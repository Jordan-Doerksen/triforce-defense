# The deck

One plate per sealed decision in `../DECISIONS.md`. Each plate: kicker · title · one visual (SVG) · 3–5 paragraphs · wax seals for the verdicts.
Citations never sit on a plate — they live in `SOURCES.md`, one section per plate.
Skin: `deck_vellum_ds.css` (night ground, vellum plate, gilt rules, Cinzel / Cormorant / IM Fell). `_retired-deck_dispatch_ds.css` is the first attempt, kept for the record.
Build order: the one sentence → the clock → the two armies → the province (plots, gate, sites) → the wild (rituals, loot).
No plate is written before its decision is sealed.
